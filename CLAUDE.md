## Personal Notes

- Forked for learning purposes and personal experimentation
- Remember to keep API keys out of committed files (use `.env` locally)
- Prefer verbose logging during dev sessions to help with debugging
- Run `black` and `flake8` before committing any Python changes
- Also run `mypy` for type checking before pushing to remote

## Local Dev Setup

- Python 3.11+ recommended (tested on 3.11.4)
- Create virtualenv: `python -m venv .venv && source .venv/bin/activate`
- Install deps: `pip install -r requirements.txt`
